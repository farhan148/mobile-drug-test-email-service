# Agent Factory 2nd Edition - Email Services

Email services project for the second edition of the book.

Book site: https://agentfactory2.panaversity.org/five-horizons/

## Structure
- `templates/`   - email templates (welcome, launch, updates)
- `subscribers/` - subscriber lists / import-export files (keep out of version control)
- `campaigns/`   - campaign drafts and schedules
- `docs/`        - plans, provider notes, requirements
