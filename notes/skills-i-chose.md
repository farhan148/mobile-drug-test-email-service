# Skills I chose

Searched skills.sh on 2026-11-08 with: email marketing, email sequence, campaign plan, resend.
Star counts come from GitHub the same day. Nothing is installed yet.

## Use these

1. **anthropics/knowledge-work-plugins** (for writing campaigns)
   - Official Anthropic publisher, 35,193 GitHub stars, updated yesterday.
   - Has `campaign-plan` (3.4K installs) and `email-sequence` (3K installs), the two jobs we need.
   - Its install numbers are lower than community copies, but a big, active official repo is a safer bet than a big number alone.
   - Runner-up: `coreyhaines31/marketingskills` (59K stars, `email-sequence` at 55K installs). Popular and active, but one person's repo, not an official one.

2. **resend/resend-skills** (for sending email)
   - Published by Resend itself, the service we plan to send through. 211 stars, updated this week.
   - `resend` (24.4K installs) covers sending; `agent-email-inbox` and `send-email` are in the same repo.
   - Worth pairing later with `resend/email-best-practices` (147 stars, also official).

## Avoid these

1. **caffeinelabs/skills@extension-email-marketing**: the top result for "email marketing" with 30.6K installs, but its GitHub repo has only 2 stars. Thousands of installs with almost no stars suggests inflated or automated numbers.
2. **claude-office-skills/skills@email-marketing**: 5.2K installs against 569 stars, from an unofficial publisher, and the repo hasn't been updated since January 2026. A weaker call than the first one, so check it yourself before dismissing it.

## How I decided

1. **Who publishes it?** Prefer official publishers (anthropics, resend) over anonymous accounts.
2. **Do installs match stars?** Check the GitHub repo. Many installs with few stars is a warning sign, because install counts can be faked.
3. **Is it maintained, and what does it do?** Look at the last update date, and read the skill's files before installing, since a skill can tell Claude to run commands.
