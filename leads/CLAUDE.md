# Rules for the leads folder

These rules apply only to files in `leads/`.

- Everyone in `leads.csv` is a made-up practice person. They are not real.
- Never add real people or real email addresses to this folder.
- Every row needs a `consent` value. Do not leave it empty.
- Never change the `@example.com` addresses. Every address must end in `@example.com`.
- Keep these columns, in this order: `first_name,last_name,email,group,joined_on,consent`.
- Groups are `tea-curious`, `gift-buyers` and `daily-drinkers`. Keep 8 people in each.
