# Rules for the leads folder

These rules apply only to files in `leads/`.

- Everyone in `leads.csv` is a made-up practice person. They are not real.
- Never add real people, real email addresses or real phone numbers to this folder.
- Every address must end in `@example.com`. Never change them.
- Every row needs a `consent` value and a `phone_consent` value. Do not leave either empty.
- Never record test results, donor details or case details here.
- Do not store phone numbers at all.
- Keep these columns, in this order: `first_name,last_name,email,company,group,source,consent,phone_consent`.
- Groups are `employers`, `individuals` and `existing-clients`. Keep 8 people in each.
